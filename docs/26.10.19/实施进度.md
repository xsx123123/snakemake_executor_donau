# 实施进度（2026-10-18）

原目标保持为两份优化文档的 Phase 0–3。用户最新说明：真实多瑙集群测试由用户执行，本轮交付实现、本地证据和可运行的集群测试脚本；不把尚未执行的真实集群验收标为通过。

## 已实现

- Phase 1：官方 run_jobs 扩展点提供真正的有界并发；run_job 保持同步拿到 external ID 后上报。命令构建/回调在调度线程，CLI 在 worker；最多N个在途提交，N=1–64、默认16；关闭时排空。
- 资源映射、作业名、entry point、CommonSettings、成功/失败集合保留；3次提交重试、2s/4s退避保留；失败诊断有界 gather，超时回收进程。实际 interface9.x 用 dataclass，修复原 Field 注册无效问题。
- Phase 2：rust/src 的协议、CLI、状态、scheduler、metrics完整模块；JSONL hello/poll/submit/cancel/diag/shutdown；request_id相关；Semaphore、有界1024channel；批量活跃/历史查询；独立1s同步、5s轮询、30s指标任务；EOF排空。
- journal：提交intent先于外部副作用并fsync；提交/终态同步；快照/归档保留7天；追加事件每50MiB滚动，快照另计，避免十万级活跃快照大于阈值后的反复重写；写/滚动失败停止新增未跟踪提交；完整坏行拒绝恢复，非完整末行安全截尾。
- 恢复：稳定输出身份不依赖瞬态jobid/重启后的attempt；活跃身份复用ID；终态才允许新代次；intent用精确作业名对账，同名旧代次ID排除；UNKNOWN/不唯一拒绝盲目重提。默认列孤儿清单，recover_orphans可选持续跟踪。
- Python sidecar客户端：并发相关请求、30s期限、stderr/metrics转发、最多3次连接重启、关闭；legacy降级通过共享flock/journal对账，保持不双写。
- 0.2.0平台wheel构建脚本、Rust release构建、源码包内Rust/测试夹具/集群测试入口。
